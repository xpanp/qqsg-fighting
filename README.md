# QQ 三国战报 · by ppp

浏览器本地录制与 OCR 工具。用户无需安装 Python 或客户端；服务器只分发静态网页和模型，录像、识别和消息整理都在用户本机完成。

第一阶段：选窗口并框选聊天区，按分钟保存视频，在本地识别并展示跨帧合并后的消息。暂不包含登录、上传、多人合并、阵营、击杀统计或 Excel。

## 使用

建议使用近期桌面版 Chrome / Edge，通过 HTTPS 打开部署页面。

1. 选择录像保存目录；浏览器要求授权时由用户确认。
2. 选择 QQ 三国的“窗口”，不能选择整个屏幕或浏览器标签页。
3. 在预览画面拖框，框住完整聊天区，建议开启游戏消息时间。
4. 点击“开始录制”。每分钟保存一段 WebM 视频及配套 JSON 时间信息。
5. 默认同时识别文字，可暂停识别而继续录像。下方显示本地合并后的消息，默认每分钟把本会话最新版保存到所选目录，停止时再保存；也可立即保存或手动导出 TXT。
6. 结束时点“停止并保存”，确认最近的视频显示“已保存”，再关闭页面。

录制状态、缓存数据块和最终文件保存是不同状态。“已保存”只在视频与时间文件均关闭提交成功后显示。失败的缓存片段可下载恢复视频及时间信息，较早的未保存片段不会被最近十条记录隐藏。

首次 OCR 从当前网站下载约 73 MiB 模型和约 28 MiB 运行库，显示实际下载量、进度及准备阶段，后续按资源校验值缓存。模型下载完仍需校验和启动，页面会分别说明。优先使用 WebGPU，失败时回退 WASM。识别慢不会阻塞录像，但可能漏掉快速滚过的消息。

视频同名 `.json` 是**视频时间说明文件**，记录采集起止时间、选区、会话与片段编号，请和视频一起保留；它不是文字识别结果。文字另外保存为每会话一组 `_messages.txt` 与 `_messages.json`：TXT 可直接阅读，JSON 保留消息 ID、采集时间和修订等信息。每次覆盖为本会话最新完整快照，避免 OCR 纠正后追加重复。两份消息文件并非跨文件原子事务；只有都关闭成功才显示保存成功，失败保留浏览器消息副本供重试。

## 模型来源与服务器流量

浏览器只从当前部署站点同源下载资源，不访问公开模型仓库或在线 OCR。ModelScope/npm 仅在开发部署准备时使用。

首次访问并准备识别会产生约百 MiB 的下载，多个用户同时首次使用会占服务器出口带宽。模型缓存后再次使用流量较少，页面和资源仍可能产生加载/校验请求。持续录像、OCR 和消息合并均在用户电脑运行；本阶段没有业务长连接、消息轮询、视频或文字上传，不是“保持一条连接就完全没有流量”。

## 开发

需要 Node.js >=22.12 和 npm，不需要 Python。

```powershell
npm ci
npm run prepare:assets
npm run dev
```

打开终端显示的 `/fighting/` 地址。准备脚本从国内 ModelScope 节点下载 PP-OCRv6 模型和字典并校验 SHA256；运行库来自锁定的 npm 依赖。开发依赖可用 `npm ci --registry=https://registry.npmmirror.com` 安装。不要在源码中写入个人路径或密钥。

```powershell
npm test
npm run typecheck
npm run build
npm run preview
```

构建产物在 `dist/`；部署操作见 [deploy/README.md](deploy/README.md)。默认部署到 `https://jinbaofu.cn/fighting/`，保留原首页业务。

## 限制

- 这是辅助记录工具。OCR 仍可能错字、漏字；消息合并不保证完整或准确，也不是游戏服务器的权威事件记录。
- 相同时间、相同位置的近似消息可能无法与 OCR 错读完全区分。算法使用相邻消息顺序、时间和位置保守合并，不按永久全文 Map 去重。
- 页面必须保持开启。后台冻结、电脑休眠、停止共享、关页或浏览器崩溃会中断采集，最后未提交的数据可能丢失。
- IndexedDB 受浏览器配额限制。已确认写入目录的片段会释放视频块缓存；未保存部分保留恢复。清理站点数据会删除本地缓存与消息。
- 文件目录授权通常需要重新选择；网页不能静默访问用户任意目录。恢复视频从第一块按顺序组装，不能把单块当成独立视频。
- 本阶段只保存合并消息和首次/最近来源帧标识、修订摘要，不保存全部原始 OCR 观察；视频是后续离线重处理的依据。
- 自动检查、合成录制和真实窗口长时间录制的验证范围分别记录，未验证条件不能当作稳定性承诺。最终是否符合使用预期由用户验收。

## Git 范围

只提交源码、锁文件、必要配置、合成测试及文档。不提交模型权重、真实录像/聊天、运行库拷贝、构建产物、缓存、个人 SSH 配置或密钥。旧验证资料可保留本机 `.tools/`，不属于生产构建或提交内容。
