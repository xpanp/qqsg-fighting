# ADR-0009 分段编码器串行切换与录像优先

日期：2026-11-26。状态：本地已采纳，未部署。

此前先启后停会短暂持有两个编码器，模拟严格单编码器资源限制可复现启动失败。选择收到旧编码器 onstop 后再启动下一段；文件写入不作为后继启动门槛。接受短暂切换间隙，避免对编码器并发可用性的隐含依赖。不能将连续 requestData 的块直接各自当独立 WebM 文件，后续块可能缺少文件头。

录像错误按片段记录；全局停止不使健康前段失效。OCR 独立 Worker、单飞、取消时 terminate，取消序号不改变录像回调身份。转移截图 buffer 降低复制开销；不能据此承诺 GPU/磁盘/内存绝对隔离。

验证与剩余限制见 [SPC-0007](../spc/0007-recording-priority.md)。
