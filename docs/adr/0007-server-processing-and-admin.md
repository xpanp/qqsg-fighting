# ADR-0007：Go 单服务、可重算数据及隔离管理入口

- 状态：已采纳并本地实现；生产验收未执行。
- 记录日期：2026-11-24；方案复核与落地：2026-11-24—25。
- 相关规格：[SPC-0006](../spc/0006-server-collection-and-admin.md)。
- 取代：无；扩展现有前后端同仓边界。
- 记录性质：事前方案。

## 背景与选项

少量采集者、多来源修订、服务端名单和单 admin 是当前规模，需保留今后用户/场次归属，部署不能影响静态采集。

| 选项 | 收益 | 成本/风险 |
| --- | --- | --- |
| 多个处理服务、消息中间件、独立数据库 | 横向扩展 | 当前运维与一致性复杂度高 |
| Go 模块化单服务、SQLite、持久任务 | 部署简单，事务和重算可验证 | 写入串行、单机容量需实测 |
| Go + PostgreSQL | 并发与运维工具成熟 | 本期多一项服务与备份维护 |

## 建议决策

本期采用 Go 模块化单服务、SQLite（WAL、外键、短事务、受控写并发）和库内任务表，不引入消息中间件。接收落盘与后续解析分开，崩溃后任务可恢复。存储层封装事务和迁移，达到写锁/吞吐/多实例瓶颈时再评估 PostgreSQL，不宣传数据库可以无成本更换。

保留来源消息及修订、跨来源关联、解析事件、标准角色身份、配置版本、人工覆盖和审计。统计为可重建投影；修订和人工纠错可撤回旧结果。名单文本是可读导入/导出格式，数据库保存版本与启用指针，不允许外部文件修改静默覆盖管理员变更。

仅一个 admin，管理查询、SSE 和导出都在服务端鉴权；公开页面不挂管理导航。采集凭据与 admin 权限分离，凭据不可编入公开资源。管理员会话 Cookie、CSRF、防爆破和凭据撤销在实施中落实。SSE 使用同源管理员会话，提供游标重连/全量快照恢复；上传使用普通 HTTP，不要求采集端长连接。

静态产物和 Go 二进制作为同版本 release 原子切换；运行数据、名单、凭据、日志与备份分离且不在 Nginx 静态根内。Go 仅监听 loopback，由现有 Nginx 代理指定路径；后端不可用时静态页仍可访问。迁移优先增量兼容，回滚程序与恢复数据库分别规划。

## 后果与验证

接受单机部署和数据库写入上限，验收通过真实多来源回放与故障测试，不以选型代替测量。备份采用数据库一致性备份方式，不只复制正在运行的 `.db` 而遗漏 WAL；名单版本与审计随数据一起恢复。2026-11-25 已创建隔离的本地测试数据库/admin，未在生产部署数据库、Go 服务或账号。目录与职责见 [第二阶段设计](../phase-2-design.md)，证据见 [验证记录](../tasks/2026-11-24-phase-2-validation.md)。
