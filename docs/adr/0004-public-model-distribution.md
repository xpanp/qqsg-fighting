# ADR-0004：模型公网下载，页面与运行库同源

- 状态：已采纳（历史补录）。
- 记录日期：2026-11-24；原需求与实现日期：2026-11-22。
- 关联：[SPC-0003](../spc/0003-public-model-source.md)。
- 取代：此前权重随静态站点发布的策略，该旧策略当时未建立独立 ADR；不取代 ADR-0001 的本地计算决策。

## 背景与选项

用户希望自行维护网页，但不承担每位用户约 73 MiB 模型的首次下载流量。

| 选项 | 收益 | 代价 |
| --- | --- | --- |
| 本站分发全部资源 | 同源配置简单、控制完整 | 模型出口带宽 |
| 自建对象存储/CDN | 可控的分发与缓存 | 额外服务配置和费用 |
| 直接使用固定版本公开模型链接 | 权重不经本站、符合用户选择 | 第三方可用性、跨域与网络限制 |

## 决策

按用户明确选择，manifest.url 指向固定 ModelScope v3.10.0 权重地址。浏览器直接下载、SHA256 校验并缓存，沿用旧虚拟缓存键以复用已校验文件。构建不再包含 ONNX 权重，不静默回退到本站。网页、字典和 ONNX Web 运行库仍同源。

## 后果与验证

本站仍承担页面及约 28 MiB 运行库流量；公开源接收下载请求，不接收采集画面或文字。必须验证真实 GET 在 CORS/跨域隔离下可用，HEAD 或单元替身不足以证明。

依据：[原实施及冷启动验证](../tasks/2026-11-22-public-model.md)。未来换域、换模型或自动回退需重新评估校验、缓存、带宽与用户提示，并记录新的决定。
