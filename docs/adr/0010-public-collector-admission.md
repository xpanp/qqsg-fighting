# ADR-0010：公共访客采集接入与活跃上传限额

- 状态：已采纳；本地实现及独立验证通过；用户验收另计，未部署。
- 记录日期 / 决策日期：2026-11-26。
- 相关 SPC：[SPC-0008](../spc/0008-automatic-collector-and-source.md)。
- 取代：部分取代 [ADR-0006](0006-durable-message-sync.md) 中普通用户手动填写接入信息、默认关闭与单独同步开关的产品决策；沿用其独立 outbox、授权范围、幂等与失败隔离。
- 记录性质：用户选择公共自动接入后补录，代码已有草稿，非事前完成记录。

## 背景与决策驱动因素

当前仅邀请同一区服伙伴使用公共网址，尚不做用户系统。用户不应逐人配置凭据；同时需要控制服务器负载，默认最多十个采集端同时上传。角色 OCR 不能充当鉴权依据。

## 考虑的选项

| 选项 | 收益 | 成本或风险 |
| --- | --- | --- |
| 管理员手工发凭据 / 专属邀请链接 | 公共写入面小、可控 | 用户明确选择公共网址自动接入，不采用本轮方案 |
| 网页内置共用上传密钥 | 客户端简单 | 密钥公开、无法逐设备撤销，不采用 |
| 公共注册，发每浏览器独立只写凭据 | 用户无需配置、兼容现有上传API、可撤销 | 新增公共写入面，需限额、退避和运维关闭 |
| 先实现完整用户登录 | 更强归属和权限 | 超出当前单区范围，留待后续多区 |

## 决策

采用独立访客凭据：同源 JSON 注册接口返回随机 sourceId/token，服务端只保存哈希，浏览器复用凭据。通过独立Web Lock在锁内重新读取、注册和持久化，防止多标签页覆盖身份；锁不进入录像等待链。服务器只接收文字及来源观察，不接收视频、图像或浏览器文件句柄。管理员身份与采集token完全分离。

开始录制后默认开启本次文字同步，移除普通页开关/配置；保留清晰简短的数据去向说明和同步状态。默认开启不等于回传从未授权的历史会话。401/已撤销不自动申请新身份绕过撤销。

活跃名额按source计数，不当作真实人数：默认十个，两分钟租约，有效校时/上传请求续期，过期及撤销释放。满额429并退避，录像和本地OCR继续，待传队列有上限。另设注册IP/全局频率与历史总量限制、上传IP/全局频率限制，状态有界。生产反代IP信任边界必须核查。

## 后果与验证

接受访客身份不可信、同人多浏览器占多名额、两分钟内离线名额未立即释放、不保证公平排队。恶意访客仍可能占用有限名额；限流降低资源消耗，不等于防作弊或实名授权。必要时关闭公共注册、撤销来源，未来多区用户系统另建规格。

验证第11来源被拒、续租不增人数、过期/撤销释放、注册并发不超总量、旧凭据复用、跨源拒绝、只写token不能访问admin、同步失败仍录像。草稿测试结果与主项目完整验证必须分开记录。
