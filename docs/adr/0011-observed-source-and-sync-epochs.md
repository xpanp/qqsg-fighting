# ADR-0011：观测来源身份与同步逻辑会话

- 状态：已采纳；本地实现及独立验证通过，未部署。
- 记录日期 / 决策日期：2026-11-26。
- 相关 SPC：[SPC-0008](../spc/0008-automatic-collector-and-source.md)。
- 取代 / 被取代：不取代录像会话与修订身份；扩展 [ADR-0006](0006-durable-message-sync.md) 的同步上下文边界，沿用 [ADR-0009](0009-recorder-resource-isolation.md) 的录像优先。
- 记录性质：用户需求和首轮实现/Review 后补录。

## 背景与决策驱动因素

标题栏可以提供服务器和线路，左上HUD可提供角色。聊天录像只保存选区，身份需要另从已授权窗口的小区域读取；不能因此扩大录像范围或把身份文字当聊天。

wire v2 的同一同步会话 context 不可变。先传未知区服再直接补同一会话，或换线时给旧消息重贴线路，会产生冲突及错误合并。录像会话也不能为换线而被迫停止。

## 考虑的选项

| 选项 | 收益 | 成本或风险 |
| --- | --- | --- |
| 每次都让用户手填来源 | 明确 | 交互复杂，不符合本轮目标 |
| 将 OCR 角色名当用户或凭据 | 接入表面简单 | OCR不可靠且可伪造，不采用 |
| 换线后修改整个同步会话 | 改动少 | 违反不可变context并污染旧事件，不采用 |
| 每消息新增context并升级v3 | 表达灵活 | 扩大迁移，本轮无需 |
| 录像会话稳定、身份变化建立同步逻辑会话 | 兼容v2、旧数据归属稳定 | 需持久化映射与明确观察边界，采用 |

## 决策

来源识别独立纯解析，读取已授权窗口标题及角色栏；截图不上传。窗口label仅初始后备，实时标题优先；角色只能来自姓名区域或明确标签。文字标准化仅限线路等字段，角色标点不得盲删。

身份观察以取图时间为证据，连续一致观察后才确认；缺失/冲突中断稳定计数。识别未知不阻止录制，页面显示未识别。当前不引入用户归属、多区权限，也不将OCR结果称为身份认证。

聊天识别优先，身份识别低频并使用同一有界调度，避免并发占用模型；但身份错误不得关闭正常聊天识别。首轮Review发现的阻塞已修复并复验：聊天先完成，身份5秒超时后只退避该任务，下一轮重建Worker而不关闭OCR。共享硬件资源的限制继续保留。

保留录像 session ID，另建同步 epoch：首次未知可用空上下文；后续确认/变化建立新的同步session，保存 captureSessionId/captureFromMs 映射。消息按首次观察时间归属epoch，修订沿用原归属。时间边界采用连续确认帧的取图时间，不使用推理完成时间。消息首次入队后固定归属，后续修订不得因边界变化迁移到另一epoch；持久化归属由assignments与入队同事务完成，ACK后/重开后不变；队列满则事务回滚，已通过回归。

已上传的未知来源数据保持未知，不静默修改或伪造为新确认身份；当前不做历史unknown自动回填。以后若需纠正应通过显式可审计重算方案，不修改现有不可变会话上下文。

## 后果与验证

身份观察有延迟与OCR误差，换线瞬间事件不保证精确归属，游戏内事件时间与画面采集时间仍分开。当前固定HUD区域对DPI、标题栏是否采集和UI布局需要实测；无法明确识别就保持未知。

需测试旧label与新标题冲突、A/未知/A不被算连续确认、推理延迟不推迟采样边界、换线不停止录像、不重贴旧消息修订、身份文本不进入聊天合并、初始unknown不会伪装已知。首轮缺陷已修复并通过独立复验；真实窗口长录制和多DPI仍待验收，见 [验证报告](../tasks/2026-11-27-automatic-collector-validation.md)。
