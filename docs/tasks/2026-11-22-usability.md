本任务交付时模型、字典和运行库均同源提供；随后用户决定将权重改为公开源，现行行为见 [公开模型源任务](2026-11-22-public-model.md)。本地录制 OCR 无业务上传，无持续业务 WebSocket 或轮询。

视频同名 JSON 是视频时间说明文件，记录实际起止时间、会话/片段编号、选区与数据块摘要；消息另有 `_messages.txt` 与 `_messages.json` 快照，含本会话最新合并结果。浏览器 IndexedDB 仍是本地消息副本；关闭或清站点数据前以目录成功保存提示为准。

验证与审查：63 项独立回归和生产构建通过，浏览器 GPU/CPU 与实际 OPFS 快照验证见 [验证记录](2026-11-22-validation.md)。本轮代码完成，实际系统目录授权和长期录制继续由用户验收；发布版本通过 GitHub 和线上 version.json 核对。
