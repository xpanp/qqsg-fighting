## 浏览器实际运行

2026-11-21，Codex 内置 Chromium 158，Windows，安全上下文与 crossOriginIsolated 均为 true。验证按钮仅存在本地、Git 忽略的 harness，不包含在生产入口。

- 实际 MediaRecorder 对合成 Canvas 连续录制 91 秒，测试切段周期 30 秒。
- 4 段均完成 OPFS 视频和 JSON 关闭提交：356599、354621、343995、19323 字节；目录文件大小与片段记录一致。
- 实际片段时长元数据约 30.057、30.039、30.041、0.987 秒，切段时间记录明确，允许少量重叠。
- 85 次数据块提交，4 次保存完成，无记录器错误；视频元数据均可加载。WebM duration 显示为 streaming-duration，本次未以元数据加载代替逐帧解码验证。
- 录制 3.5 秒时，恢复到已提交的 3 块、49141 字节；此处验证的是读出已提交块，并非整浏览器崩溃后恢复。
- 同时运行生产 OCR Worker 和 PP-OCRv6：GPU 初始化冷启动约 1.81 秒；缓存命中热初始化约 0.96 秒；8 行真实游戏样本热识别约 348 毫秒。
- 识别结果仍有生僻字和装饰名字错误，没有宣称准确率达标。

OPFS 写入代表真实浏览器文件 API 路径验证，不代表已经验证系统目录选择器或真实游戏窗口共享。测试资源保留本地 .tools/，不提交真实样本或聊天结果。

## 用户验收与已知限制

真实桌面 Chrome/Edge 的窗口与目录授权、60 分钟真实游戏录制、后台冻结、系统休眠和配额耗尽仍待人工验收。已通过单测故障注入检查写入/关闭失败行为，没有填满用户磁盘。

合并仅保存最终消息与首末帧摘要；同秒同位置的近似不同消息仍可能与错读混淆。分行边缘过滤为启发式，不保证每条都完整。关页或崩溃最后未提交尾部可能丢失。

交付的是等待用户验收的第一版，不是已经完成小时级稳定性认证的正式产品。部署由 scripts/deploy.ps1 从审查后的单个提交重新构建；最终 SHA 通过 GitHub 历史及线上 `/fighting/version.json` 核对，服务器 release/deployment.txt 记录回滚依据。
