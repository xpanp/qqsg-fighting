## 高风险回归

旧 Demo 迁移需重点验证：

1. 创建与启动失败不能留下虚假的录制状态或永不完成的片段。
2. MediaRecorder 错误后停止不能永远等待未结束的 Promise。
3. 停止与异步创建下一段竞争时，不得在用户停止后继续创建录制器。
4. 存储错误后不能把尚未关闭的文件误报为已保存。
5. 长录恢复只读取目标片段；缓存清理不得删除未保存数据。
6. 模型初始化失败可重试；前一会话迟到的 OCR 结果不能写入新会话。

## 真实浏览器人工验收

分别记录桌面 Chrome、Edge 版本，日期、机器、推理路径、步骤、文件和结果。以下不能由 Node 替身或合成画面替代：

- 实际选择 QQ 三国窗口、拒绝/取消选择、误选屏幕或标签页、框选边界和重选。
- 实际目录授权、停止共享、目录授权丢失、刷新恢复和用户操作提示。
- 至少 60 分钟真实录制；检查全部视频可解码、持续时间、相邻段时间间隙/重叠及最后短段。
- 前后台、最小化、休眠中断；明确浏览器限制，不宣称后台或关页持续录制。
- 部署 HTTPS 页面下载模型、启动 Worker、录制、OCR、合并、保存。
- 网络确认只下载静态资源，无截图、视频与消息业务上传。
