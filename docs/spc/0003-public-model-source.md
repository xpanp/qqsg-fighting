# SPC-0003：模型权重使用公开下载源

- 原需求日期：2026-11-22；本文件于 2026-11-24 事后整理。
- 状态：已交付待用户验收。
- 新增决策：[ADR-0004](../adr/0004-public-model-distribution.md)。

## 目标、范围与约束

网页继续在用户服务器维护，约 73 MiB 模型权重直接从固定版本 ModelScope 公开地址下载，减少本站流量。字典和约 28 MiB 运行库仍同源；识别仍在本机，公开源只接收资源请求，不接收采集内容。

不做 CDN 采购或多源自动切换。保留 SHA256、进度和原缓存键；源不可用时明确失败，不静默回退到本站权重。

## 验收与任务

| 工作与验收 | 原验证 |
| --- | --- |
| manifest.url 固定版本，Worker 从该地址下载 | 实现与独立 Review |
| 旧已校验缓存可以复用，冷下载使用外链 | 资源加载回归 |
| 准备脚本不下载权重，部署产物不含 ONNX 文件 | 原构建与部署检查 |
| CORS 与跨域隔离环境冷启动可用 | 新 origin 冷缓存浏览器实际下载、校验并 GPU 就绪 |
