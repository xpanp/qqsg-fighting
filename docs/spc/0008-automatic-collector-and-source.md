# SPC-0008：自动采集接入与来源识别

- 建立日期：2026-11-26。
- 状态：待用户验收；2026-11-27 本地实现、自动检查和独立复核通过，未部署。
- 需求来源：用户要求展示服务器、线路、角色；同步默认开启、普通用户无需配置；选择公共网址自动接入；最多十个采集端同时上传；当前仅用于同一区服。
- 负责人：主 Agent 协调；身份解析、后端接入、独立测试与架构 Review 分工执行。
- 相关 ADR：[ADR-0010](../adr/0010-public-collector-admission.md)、[ADR-0011](../adr/0011-observed-source-and-sync-epochs.md)；沿用 [ADR-0006](../adr/0006-durable-message-sync.md)、[ADR-0009](../adr/0009-recorder-resource-isolation.md) 的故障隔离约束。
- 记录性质：需求讨论与初步实现后补录。此前未先建立本规格，不伪称事前规格或已完成验收。

## 问题与目标

伙伴打开同一个公共网址，选目录、选游戏窗口、框聊天区、开始录制即可。无需管理员逐人发链接，无需填写来源编号、区服、线路或接入凭据。开始录制后默认同步本次识别并合并的文字；服务器、线路、角色能明确识别就展示，未识别不阻止录像。当前不增加用户注册、登录和多区归属管理。

## 范围与非目标

包含：公开采集凭据注册、最多十个活跃上传来源、来源身份低频识别和展示、同步上下文隔离、普通页面去掉单独同步开关、数据去向告知、断网重试、管理员沿用现有撤销入口。

不包含：用户管理、可信角色认证、多区权限、服务器 OCR、上传截图/视频、改变录像裁剪区域或文件格式、无法实现的绝对零丢失保证。本轮功能与上一轮录像修复均未因本地修改自动部署。

## 行为与约束

### 普通用户流程

1. 选择保存目录和 QQ 三国窗口，必须框选聊天区，开始录制。
2. 录制启动不等待凭据注册、身份识别、模型下载或文字网络请求；OCR 可单独暂停。
3. 页面移除同步开关和凭据输入，但保留可见短说明：识别后的聊天文字及区服、线路、角色信息会同步到本站服务器，截图和视频保存在本机。
4. 展示“服务器 / 线路 / 角色”；未知明确显示未识别，不伪装为已确认，不默认填12线或示例角色。当前单区使用不要求用户补全这些信息。
5. 角色名表示游戏采集视角，不等同账号、上传者真实身份或鉴权凭据。用户未开启 OCR 时仍可正常录制，无 OCR 结果无需上传。

### 来源识别

- 来源为已授权的完整游戏窗口：窗口标题和左上角色栏。连续确认的时间边界取确认帧的采样时间；缺失候选应重置稳定计数。额外小区域仅本机识别，不扩大录像选区，不上传图像。
- 标题解析服务器及线路，规范化数字线路；角色仅从专用姓名区域或明确角色标签读取，不能从聊天内容任取人名。
- 窗口 track label 仅初始参考；实时截图标题优先，不能用旧 label 覆盖已换线的新画面。
- OCR 观察连续至少两次一致才确认变化，缺失或冲突重置计数；窗口重选清除旧来源。坐标、标题栏是否被采集及 DPI 适配需实际图像验证，未知保守处理。
- 身份识别共用有界单飞调度，不新建并发推理。聊天识别优先，身份失败不得关闭聊天 OCR，更不得停止录像。身份任务时限与恢复需验证，不能以“低频”代替隔离。

### 默认同步与自动接入

- 仅开始录制后为缺少凭据的浏览器请求 `POST /fighting/api/v1/collectors/register`；同一浏览器复用独立只写 sourceId/token，失败有限退避。
- 现有有效凭据可复用。401/撤销不通过重新注册绕过；公共 JS 不内置管理员或共享上传密钥。浏览器本地持久化失败仅影响标识复用，不影响录像。
- 默认开启仅作用于本次新采集会话；不得扫描并上传从未授予同步范围的旧私人会话。已有授权待传消息仍按原归属补传。
- 身份未知时保留空字段和未知语义；确认身份或换线后建立新的同步逻辑会话。录像会话不中断；消息首次入队后固定归属，旧消息及修订保持原上下文，不整体重贴新线路。
- 同步保留独立有界 outbox、逐项确认、去重与退避。满额、超时、断网、服务端失败仅影响同步；队列满需明确提示，不承诺无限缓存或无限补传。

### 十个活跃上传来源

- 按独立浏览器 source 计数，不声称十个真实用户；同一人两个浏览器可占两个名额。
- 默认同时最多10个来源，`--max-active-collectors` / `MAX_ACTIVE_COLLECTORS` 可调。使用2分钟租约，由有效校时/上传请求续期，过期或管理员撤销释放。
- 超额返回429与 Retry-After，前端显示本地仍在记录并有限退避重试；名额释放不是立刻通知，也不承诺公平排队。
- 公共注册另有限制：每IP每小时10次、全局每小时100次、历史凭据总量1000（含撤销）；上传仍有来源/IP/全局请求限制。有界状态避免无限内存或数据库增长。
- 生产代理只能信任受控反代提供的客户端IP；管理员接口不受访客名额占用影响，仍独立鉴权。
