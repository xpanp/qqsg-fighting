## 行为与验收

选定目录立即创建随机测试文件，实际createWritable、write、close，关闭成功才接受该目录；清理只针对本次自建随机文件。删除失败提示残留但不误判不能写。选择目录和检查期间禁用开始按钮，失败清除候选，立即显示目录名称、失败阶段、错误类型及重新选择提示；用户取消选择保留原有效目录。每次开始前再验证，失败不创建MediaRecorder，不把准备失败显示为录像中止。路径不限定盘符或中文。

小文件成功不保证未来空间足够或权限一直有效，录制时保存失败与可恢复缓存继续保留。独立测试覆盖所有写入阶段、清理失败、UI等待和开始前失败，Review独立核查。2026-11-27用户追加授权：完成检查后直接部署，无需等待其返回确认。
