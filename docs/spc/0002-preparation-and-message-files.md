# SPC-0002：识别准备进度与文字自动保存

## 问题与范围

用户不知道下载是否有进展、视频 JSON 有什么用途，消息又只存在浏览器中。本轮提供提前准备、实际下载进度、缓存/校验/初始化阶段提示，解释时间说明文件，并将本会话最新消息自动写入所选目录。加入产品经理的体验检查职责。

不做在线 OCR、业务同步或服务端存储。模型当时同源，随后由 SPC-0003 换源。

## 任务与验收

任务 U1—U4 保留在 [实施记录](../tasks/2026-11-22-usability.md)。

| 验收项 | 证据与限制 |
| --- | --- |
| 下载按真实字节报告；未知总量不伪造百分比；进度不误完成请求 | 资源加载器与客户端回归 |
| 模型下载后区分校验/启动；缓存损坏可重下，缓存不可用可降级 | 独立回归；浏览器 GPU/CPU 路径验证 |
| 每分钟及停止时写本会话 TXT/JSON；修订不重复追加 | MessageArchive 回归及 OPFS 周期/最终写盘读取验证 |
| 写/关闭失败可重试，保留浏览器副本且不影响录像 | 故障注入覆盖；两文件不是跨文件原子事务 |
| 普通用户选择目录与长录 | 尚不以 OPFS 测试替代用户授权及长期运行验收 |
