# SPC-0007 录像优先与分段故障隔离

日期：2026-11-26。状态：本地实现与自动检查通过，待真实浏览器长时间验证，未部署。

## 目标
OCR 慢、挂起、初始化失败、文字保存或上传失败不得进入录像停止的控制链；录像优先。排查首分钟停止问题，不能把模拟复现当作用户设备根因确认。

## 实现
- 先停止旧编码器，收到 onstop 再启动后继；文件保存独立完成，不等待前段文件写完才启动后继。切换可能有短暂间隙，不承诺无缝。
- 每段独立判断数据错误；后继启动失败不阻止健康前段写入目录。错误保留阶段、名称、时间和片段 ID。
- OCR Worker 单飞，忙时跳过；停止录像或关闭 OCR 时终止推理与初始化 Worker。OCR 取消序号独立于录像会话。
- RGBA 使用 transferable，减少跨 Worker 复制。停止提示保留首个录像错误。

## 验证
生产构建通过。npm test：100 通过、0 失败、13 跳过（HTTP 集成需服务环境，本轮未重跑）。新增 2 项编码器分段回归与 6 项 OCR 隔离测试；后者执行实际 tickOcr 函数体并注入依赖，包括永不返回、真实客户端超时、初始化失败、文字更新异常与文字存储失败/挂起。

## 边界与剩余
测试使用合成编码器，不等于真实浏览器解码或长时间录制验证。GPU、主线程、内存、磁盘和同源配额仍共享，浏览器冻结/关闭、系统休眠、磁盘满、窗口共享中断无法保证继续录像。视频本身写入失败应明确失败并保留可恢复缓存，不伪报成功。
文字快照停止仍可能等待文件 I/O；主线程合并/显示与快照序列化的资源预算、压力自动降频尚未实现，本轮不得宣称完全资源隔离。线上版本未因本地构建改变。
