# SPC-0010：用户管理、独立采集名额与 PoC 完善

- 建立日期：2026-11-28
- 状态：待用户验收（已发布，待实际游戏窗口验收）
- 来源：用户附件 `qqsg-fighting-poc.md` 及本次明确修订。附件是讨论材料；冲突处以用户本次要求为准，原下载文件不修改。
- 负责人：协调者；开发、独立测试及 Review 在实施时分配。
- 相关 ADR：[0012](../adr/0012-account-capabilities-and-password-display.md)、[0013](../adr/0013-independent-admission-and-region-gating.md)、[0014](../adr/0014-report-core-and-config-recovery.md)；沿用录像隔离 ADR-0009。

## 问题与目标

在保留现有浏览器本地录制稳定性的前提下，增加独立账号权限、战报访问与文字采集准入、名单恢复及 Go 离线报表。任何登录、名额、上传或服务端故障均不得主动停止已开始的本地录像。

本轮交付本地账号版实现及验证。新账号模式由服务端启动参数启用，发布时需配对账号版前端和服务端。

## 角色与页面

角色使用显式能力，不按角色等级继承。Admin 与超管是两种独立角色。

| 能力 | Admin | 超管 | 普通用户 | 游客 |
| --- | --- | --- | --- | --- |
| 用户管理、删除、授予/撤销超管、游客开关 | 是 | 否 | 否 | 否 |
| 按需查看普通/超管原始密码 | 是 | 否 | 否 | 否 |
| 开始本地录制、OCR 与申请上传 | 否 | 是 | 是 | 否 |
| 查看战报与统计 | 否 | 是 | 是 | 开关控制 |
| Excel 导出、名单配置与恢复 | 否 | 是 | 否 | 否 |

Admin 进入独立治理页，列表展示用户名、区服、角色、注册时间及管理操作。超管和普通用户进入录制/战报页面；游客进入战报页面，默认允许访问。前端隐藏不允许的功能，后端仍逐接口验证权限。Admin 想使用业务功能应另用业务账号。本轮无修改密码、忘记密码或重置密码功能。

## 账号与密码

- 新注册用户名 **4–16 位**、密码 **8–18 位**；均允许 ASCII 可打印的字母、数字及英文符号，拒绝空白、控制字符和中文。前后端规则一致；密码不得自动 trim、改大小写或做 Unicode 归一化。
- 用户名全局唯一，按 ASCII 大小写不敏感键判重，保留原显示大小写。注册默认普通用户、无需审核；区服下拉当前只有“得陇望蜀”。登录页提供注册及游客入口，提示不要使用游戏账号密码。
- 系统内置 Admin 由服务器初始化，不开放注册；现有 `admin` 符合统一用户名规则。初始化时已设置的密码继续有效，新注册密码长度限制不追溯既有凭据。保留系统命名空间，不可删除唯一系统 Admin。
- **Admin 可以查看普通用户及超管的原始密码**，这是管理功能，不只是输入框显示按钮。采用登录哈希与可解密密文并存；仅 Admin 经单独操作获取密码，用户列表不批量携带密码。Admin 自身初始化密码只保留登录哈希、不提供原文查看。
- 密钥放服务器运行配置/凭据中，不进 Git、数据库或前端资源。查看接口 HTTPS、有效 Admin 会话、CSRF 保护、禁止缓存；审计查看者、目标、时间和结果，不记录密码。详见 ADR-0012。
- 删除账号或权限变更使相关服务端会话/能力失效；不得借此停止浏览器正在录制的本地视频。

## 四类状态独立

| 状态 | 作用及限制 | 失效后的行为 |
| --- | --- | --- |
| 登录会话 | 确认账号与权限 | 停止受保护的远端请求，保留正在运行的本地录制/OCR/保存 |
| 本地录制 | 浏览器窗口授权、选区、目录可写和录像运行 | 只有用户停止、浏览器/采集源或本地真实故障进入停止/恢复流程 |
| 战报访问租约 | 最多 100 个普通/游客在线查看会话 | 提示稍后访问；不限制登录、注册或进入录制页 |
| 文字采集租约 | 最多 10 个活跃来源上传 | 有界本地积压并退避重试；不影响录制和本地 OCR |

超管不占普通/游客战报名额；Admin 治理入口不占业务名额，但两者仍有基础限速和资源保护。100 是正在访问战报的会话数，不是所有登录用户数；同一浏览器会话多标签共用一个名额，游客使用独立不透明会话标识。

两个名额池分别申请、续租、释放及过期回收，TTL 默认 120 秒、心跳 30 秒；采集保留现有 120 秒期限。离开战报且无其他标签查看时释放访问名额，上传暂停/退出时释放采集名额，关闭页面丢失释放请求由 TTL 兜底。满额响应含重试建议，不承诺严格 FIFO。

已登录并开始录制后，退出登录、会话过期、账号删除、服务离线均只关闭远端权限，录制界面与运行实例应保留到用户停止。账号 A 正在录制时不可无缝切到 B 接管录像/队列；先停止并保存再切换。离线首次打开网页仍受资源是否已加载限制，不承诺离线冷启动。

## 上传归属与区服

- 用户注册区服及窗口识别区服均明确为“得陇望蜀”才可新建上传意图。采用相对区域、布局特征及多次稳定观测，验证不同 DPI；服务器核对账号与来源声明。客户端观测不是防伪证明。
- 未识别或其他区服：继续本地录制、OCR 和保存，**不进入可上传队列**；确认后仅从新来源周期开始，不自动补传此前未知数据。
- 队列、凭据和来源绑定不可变的 userId、device/sourceId、区服及逻辑会话；同账号重新登录可继续合法队列，B 不能补传 A 的消息。
- 新账号模式启用后关闭匿名新接入；既有匿名凭据不能绕过登录继续上传。旧本地数据保留供查看/导出，不自动归给当前账号；如需历史导入另行设计显式授权流程。
- 同步去向保留简短告知；OCR、写盘、网络各自有界，不在录像保存链路等待鉴权或名额。

## 服务端资源与恢复

维持 Go 模块化单体、SQLite 和 Nginx，不引入 Redis、消息队列或复杂 RBAC 框架。治理请求 P0、超管查询/名单/导出 P1、普通/游客战报 P2、文字上传及补传 P3，采用独立有界并发和保留治理容量，后台重算/导出不占满请求线程。SQLite 仍有写串行限制，优先级不等于无限容量或抢占承诺；10/100 必须实际压测。

名单每次变更保存完整快照、操作者、时间及动作；显示版本单调递增，可沿用现有内部 ID。恢复旧版本创建新版本并记录 restoredFrom，不改历史。当前配置切换事务化，异步重算结果只在配置版本和输入代次均匹配时发布；旧任务不能覆盖新结果。重算失败继续提供旧的完整统计并明确显示旧版本/失败状态，不能混搭新名单和旧统计。

每天使用 SQLite VACUUM INTO 生成一致性快照备份到独立运行目录，默认保留最近 30 份日备份；部署前备份单独管理。名单历史版本在 PoC 内全部保留。密钥单独受保护备份；仅恢复数据库不能恢复解密能力。异机备份留接口及人工流程，本轮不声称自动异机容灾已完成。

## Go 离线报表及数据契约

同一个 Go 项目支持 Server 和 CLI，复用解析、事件去重、人名归一化、阵营统计及 Excel 导出的处理核心；HTTP、SQLite、TXT/JSON 是适配器。核心不依赖在线鉴权或服务数据库。

拟定入口：现有 `qqsg-server` 无子命令启动行为继续兼容，增加 `server` 和 `report`；参数形式在实现时写入帮助和 README。离线输入合并 OCR TXT/JSON、A/B/others 三份名单、别称和黑名单；输出 Excel、摘要及异常记录。不把真实名单与录像提交仓库。

TXT 至少保留 `YYYY-MM-DD HH:mm:ss.SSS  [地图][HH:mm:ss]甲在战斗中击败了乙`，无偏移时间需显式指定时区（默认配置 Asia/Shanghai），区分采集时间、游戏消息时间和回放时间。多视角数据需 manifest 或 JSON 保留来源及自身角色；单一 --self-name 只适用于单视角，不能对混合来源统一替换“你”。不根据重跑日期或任意文件名覆盖战斗日期。

归一化名单沿用已存在格式并记录转换规则，明确别称映射方向。黑名单死亡者对应事件整体不计战绩；总览和 KD 只统计 A/B 互相交战，其他阵营不混入。没有助攻数据不得编造 KDA 助攻。导出包含概览、击杀、死亡、阵营及按时间筛选需要的带时间事件数据，沿用已确认报表维度。

异常输出含文件、行号、状态及原因；保留原始输入，不静默丢弃。结果记录配置版本及算法版本，可重复生成。服务端与 CLI 对相同输入必须得到一致统计。

## 交付与遗留

已完成本地前后端实现。编译、Go 测试及 vet、TypeScript 检查、Vite 构建通过。独立测试在隔离的 SQLite 和回环服务完成账号角色、密码查看、游客开关、采集和战报名额分离、注销后来源失效验证。另用同一个临时数据库从匿名模式切到账号模式，验证旧匿名凭据和无账号的新登记均被拒绝。限额测试用两个可用名额触发满额，默认值仍为查看 100 和上传 10。该测试不代表生产并发压测。

独立 Edge 测试使用真实 MediaRecorder、OPFS 和模拟游戏画面、账号接口。上传收到 429、随后退出登录，录像跨过一分钟分段并可手动停止，两个 WebM 均可独立解码。真实 QQ 三国窗口、多 DPI、原生目录权限和长时间录制仍待用户环境验收。

名单恢复测试验证新版本、来源审计及投影发布。当次历史回放以 2026-11-26 已转写消息和独立名单副本生成 XLSX 及异常摘要。SQLite 每日一致性快照复用已有 VACUUM INTO 备份路径，不含独立密钥。自动异机容灾和生产恢复演练未执行。
