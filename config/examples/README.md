# 名单文件模板

复制本目录到独立运行配置目录，再填写 `name_a.txt`、`name_b.txt`、`name_others.txt`（一行一名）。空行和 `#` 注释忽略，同文件重复去重，跨阵营冲突拒绝。

`aliases.tsv` 每行是 **标准名 TAB OCR别名**，可在同一行继续 TAB 分隔多个别名；标准名必须已在三份名单中。`blacklist.txt` 命中任一方则整条事件排除统计，原文仍保留。真实名单、备份及凭据不要放回本模板目录或 Git。

导入命令及管理页面见 [本地指南](../../deploy/phase2.md)。旧 fighting2 的别名文件列顺序相反，先转换再导入，不要直接改原始文件。
